# Topics: Control

Drone control interface topics. Schema defined in `controls.capnp`.

## Topics

- **`behave/ControlCommand`** (`command.rs`) -- flight commands from Behave to Control
- **`behave/ControlAck`** (`ack.rs`) -- acknowledgments from Control to Behave
- **`behave/DroneState`** (`state.rs`) -- telemetry from Control to all nodes
